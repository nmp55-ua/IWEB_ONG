Gestión de Donaciones y Voluntariado para una ONG

Nada · Rubén · Javi · Nicole — Astro + React · Node.js/Express · PostgreSQL · Tailwind CSS

Qué se ve en la demostración

Un recorrido de unos 2 minutos por las 8 historias de usuario, en el orden en que viajan los datos: una actividad que se crea, se llena de voluntarios y acaba sumando horas, y una donación que se paga, aparece en el historial y llega al informe de la junta. Todo es la aplicación real funcionando en local, con datos de prueba y Stripe en modo de pruebas.

Cómo arrancarla para la demostración en directo

docker compose up -d
cd backend  && npm run migrar && npm run semillas && npm run dev
cd frontend && npm run dev        # http://localhost:4321

Usuarios de prueba: coordinador@ong.test, voluntario2@ong.test, donante2@ong.test y admin@ong.test, con la contraseña de CONTRASENA_SEMILLAS del .env. Para pagar, cada persona usa sus propias claves de prueba de Stripe en su .env y la Stripe CLI reenviando a /api/pasarela/webhook (ver README).
